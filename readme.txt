ضاد — an Arabic-first block theme. RTL by design, not by translation.

== Description ==

Dhad is a full site editing theme built for Arabic from the first line:

* A calibrated Arabic type system (Tajawal for body, IBM Plex Sans Arabic for headings), self-hosted and subset so pages stay light.
* Logical CSS properties only, so RTL and LTR share one stylesheet with no rtl.css.
* Mixed Arabic/English paragraphs set their own direction automatically.
* Zero JavaScript in the front end.
* Four style variations: ضاد (default), مجلة (magazine), ليل (dark), رمل (warm).
* Ready-made Arabic patterns: hero, latest posts, features, call to action, full About page.
