# ضاد — Dhad

ثيم ووردبريس Block Theme مبني للعربية من الصفر: RTL بالتصميم لا بالترجمة.

## لماذا ضاد
- نظام طباعة عربي معاير: Tajawal للنص وIBM Plex Sans Arabic للعناوين، مستضافان محليًا ومقطّعان (252KB للخطوط كلها).
- CSS بخصائص منطقية فقط، فالاتجاهان يعملان بملف واحد بلا `rtl.css`.
- الفقرات المختلطة (عربي/إنجليزي) تضبط اتجاهها تلقائيًا.
- صفر JavaScript في الواجهة.
- 4 تنويعات أسلوب جاهزة: ضاد، مجلة، ليل، رمل.
- أنماط عربية جاهزة: مقدمة، آخر المقالات، ثلاث ميزات، دعوة للاشتراك، صفحة من نحن كاملة.

## التثبيت
1. نزّل المستودع ZIP.
2. المظهر ← القوالب ← أضف جديد ← رفع قالب.
3. فعّل، ثم المظهر ← المحرر ← الأنماط لاختيار التنويع.

## المتطلبات
WordPress 6.6+ ، PHP 7.4+

## البنية
```
theme.json      النظام كله: ألوان، خطوط، مسافات، أنماط الكتل
styles/         تنويعات الأسلوب
templates/      القوالب: الرئيسية، المقال، الصفحة، الأرشيف، البحث، 404
parts/          الترويسة، التذييل، بيانات المقال
patterns/       الأنماط الجاهزة
assets/fonts/   الخطوط (OFL)
```
